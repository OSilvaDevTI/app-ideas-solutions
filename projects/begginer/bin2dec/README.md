# Bin2Dec

Aplicação Flask que mantém a lógica original do projeto para converter um
número decimal em sua representação binária.

## Executar localmente

No diretório `projects/begginer/bin2dec`:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bin2dec.py
```

Depois, abra `http://127.0.0.1:5000`.
